This claims-assistant web application sends every AI request through LayerOne. LayerOne checks the request on its way to the AI model, then checks the answer on its way back. It removes personal information such as Social Security numbers, blocks risky requests, and keeps an audit record of everything.

Practice mode: requests go to a built-in stand-in, not the real LayerOne.
